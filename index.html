📋 El proyecto

RESET — A Game About Your Mind es un videojuego web interactivo diseñado para abordar, desde una perspectiva lúdica y educativa, la percepción y gestión del estrés cotidiano. Utiliza minijuegos para representar diferentes estados de saturación mental y conducir progresivamente al jugador hacia un estado de mayor concentración y calma.

🎯 Objetivo general

Desarrollar un videojuego web interactivo que represente diferentes situaciones asociadas al estrés cotidiano mediante mecánicas de juego, promoviendo la identificación de estados de saturación y la importancia de realizar pausas para recuperar la concentración y el control.

🔍 Objetivos específicos

  • Representar visualmente situaciones asociadas con la saturación y el estrés cotidiano.
  • Diseñar minijuegos que involucren interacción, concentración, reacción y respiración.
  • Crear una experiencia progresiva que evolucione desde un entorno de saturación hacia uno de calma.
  • Aplicar elementos de gamificación como puntuación, tiempo y sistema de récords.
  • Desarrollar una interfaz web intuitiva, accesible y visualmente coherente con la temática.
  • Implementar el videojuego utilizando tecnologías web y publicarlo mediante GitHub Pages.

⚙️ Tecnologías utilizadas

HTML5 CSS3 JavaScript LocalStorage Web Audio API GitHub Pages

💡 Justificación

¿Por qué se creó?

RESET — A Game About Your Mind surge como una propuesta para abordar el estrés cotidiano mediante una experiencia interactiva que combine entretenimiento, comunicación visual y sensibilización. En lugar de presentar el tema exclusivamente mediante información teórica, el proyecto busca que el usuario pueda experimentar una representación simbólica de la saturación mental a través de las mecánicas del videojuego.

🌟 Importancia

El proyecto es relevante porque utiliza un medio digital ampliamente accesible, como el videojuego web, para abordar una situación presente en diferentes contextos de la vida cotidiana. La gamificación transforma un tema abstracto en una experiencia participativa, donde el usuario deja de ser un receptor pasivo y se convierte en protagonista.

👥 Público objetivo

Dirigido principalmente a jóvenes y estudiantes, aunque cualquier persona interesada en una propuesta interactiva relacionada con el estrés cotidiano puede disfrutarlo. Su diseño mantiene una curva de aprendizaje sencilla, accesible para usuarios con diferentes niveles de experiencia en videojuegos.

✅ Beneficios

  • Favorecer la reflexión sobre situaciones de saturación y estrés cotidiano.
  • Presentar el concepto de manera visual, interactiva y accesible.
  • Estimular la concentración y la atención mediante mecánicas sencillas.
  • Promover la importancia de realizar pausas durante actividades de alta demanda.
  • Integrar entretenimiento y sensibilización dentro de una misma experiencia digital.
  • Demostrar la aplicación de tecnologías web en el desarrollo de proyectos interactivos.

RESET no pretende sustituir orientación profesional ni funcionar como una herramienta de diagnóstico o tratamiento. Su propósito es educativo, interactivo y de sensibilización.
